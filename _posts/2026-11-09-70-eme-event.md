Nous avons le plaisir de recevoir [Jacqueline Rwanyindo](https://www.linkedin.com/in/jacqueline-rwanyindo/) software engineer.

Voici ce qu'elle nous propose :

>Complexité qui s’accumule, évolutions douloureuses, métier qui se dilue : comment reprendre la main sur le code ?
>
>Et si un cadre simple devenait un levier de design ?
>
>Les Object Calisthenics, c’est une invitation à transformer la conception orientée objet en terrain de jeu : neuf règles, pas une de plus !
>
>En appliquant ces règles complémentaires sur des extraits de code avant/après refactoring, nous découvrirons comment :
> - apprivoiser la complexité
> - clarifier les responsabilités
> - faire émerger le métier
>
>Un  talk orienté pratique pour repartir avec des réflexes de conception applicables dès le lendemain et une grille de lecture concrète pour faire du code un support fidèle au métier.

La présentation sera suivie d’une discussion libre autour des thèmes abordés par Jacqueline.

Le meetup se passe dans les locaux de [Skolae Tours](https://skolae-tours.fr/){:target="_blank"} Tours.

Les inscriptions se passent sur [eventbrite](https://www.eventbrite.fr/e/billets-object-calisthenics-simplifier-le-code-pour-retrouver-le-metier-2003368834112){:target="_blank"}.
